🎙️ AI-Powered Speech-to-Text Transcription for Indian Languages
🌐 Overview

This project is an AI-based Speech-to-Text (STT) system designed to transcribe speech from multiple Indian languages into text with high accuracy.
Built using Python Flask, OpenAI Whisper API, and Google SpeechRecognition, the system aims to overcome the limitations of English-centric transcription tools by supporting regional languages like Hindi, Kannada, Tamil, and more.

🚀 Features

🎧 Supports multiple Indian languages

🧠 Integrates OpenAI Whisper and Google Web Speech API

🖥️ Built with Python Flask backend and responsive HTML/CSS/JS frontend

🔊 Handles different audio formats (WAV, MP3, M4A) using Pydub

⚙️ Real-time and file-based transcription

🔒 Secure and scalable RESTful API communication

🧩 Noise reduction and audio preprocessing for improved accuracy

🏗️ System Architecture

Frontend: HTML, CSS, JavaScript
Backend: Python Flask
AI Models: OpenAI Whisper, Google SpeechRecognition
Audio Processing: Pydub
APIs: RESTful APIs for model integration
